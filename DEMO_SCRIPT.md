# LeadRescue AI — Demo Script (≤ 3 Minutes)

## Canonical Lead: Rahul Sharma

The entire demo centers around **one lead** to show the complete flow.

---

| Time | Beat | What's on screen |
|---|---|---|
| 0:00–0:15 | **Problem** | "Indian SMBs lose leads daily — slow response, no prioritization, forgotten follow-ups" |
| 0:15–0:30 | **Introduce** | LeadRescue AI dashboard with real metrics |
| 0:30–0:50 | **Incoming lead** | Create lead: Rahul Sharma, WhatsApp, "I need 10 CNC machines. Need delivery to Pune urgently." |
| 0:50–1:20 | **AI analysis** | Agent Activity trace → Extracted: intent=purchase, urgency=high, product=CNC machines, qty=10, location=Pune |
| 1:20–1:40 | **Deterministic score** | Score: 93 → HOT → Score breakdown card showing each signal |
| 1:40–2:00 | **Human approval** | AI response draft → [Approve & Simulate Send] |
| 2:00–2:20 | **At-risk + rescue** | [ADVANCE TIME 20 MIN] → AT-RISK badge → [RESCUE LEAD] → Follow-up created |
| 2:20–2:40 | **Audit trail** | Timeline: received → analyzed → HOT → draft → approved → at-risk → rescued |
| 2:40–2:55 | **AWS architecture** | Architecture diagram, CloudWatch logs, deployed URL |
| 2:55–3:00 | **Close** | Impact statement, repo link, "Built with Antigravity" |

---

## Key Demo Principles

1. **AI does**: understanding, extraction, recommendation, generation
2. **Software does**: scoring, classification, policy, risk, follow-up, audit
3. **Human does**: approval before any customer-facing action
4. Show the distinction visually
5. Do NOT exceed 3 minutes
